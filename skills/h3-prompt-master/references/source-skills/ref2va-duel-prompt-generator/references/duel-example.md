# 范本：雷龙与牛来对决（15 秒 / 9 镜 / Ref2VA 六段式）

这是本 skill 的来源范本。可用于对照改写、拆解节拍、或作为 Ref2VA 对决题材的"目标形态"。

- 时长：15 秒（切点 00:00 → 00:13.500，末镜 1.5 秒）
- 镜头：9 个微镜头（第 1 镜 2.0 秒，其余 1.6–1.7 / 1.5 秒）
- 模式：Ref2VA（`<Picture 1>` / `<Picture 2>` 只定义身份 → `reference generation`）
- 双方：东方雷龙 Lei Yuan Long Jun（绝对主导方） vs 双足卡通牛战士 Jin Jiao Niu Wei（敌对阵营）
- 场景：北门前的废墟广场（一面接一面的断墙）
- 结尾钩子：远古符文亮起、北门巨影苏醒

## 3. 这份范本为什么成立

| 手法 | 范本中的实现 | 作用 |
| --- | --- | --- |
| 身份锁双保险 | `subject_definitions` 写全特征 + `his face is smooth and unmarked with no wounds`；`retention_analysis` 再复述一遍并豁免红眼/角裂 | 9 镜高速剪辑下唯一能压住身份漂移的组合 |
| 反向约束 | `aside from these features his body remains clean and unadorned` | 挡住模型给牛加盔甲、纹身、武器 |
| 阵营对立 | `the enemy-faction character` | 保证双方真打，而不是并肩作战 |
| 物证切点 | 扬尘 → 火花 → 碎石 → 爪痕 → 角尖 → 碎石 → 闪电柱 → 急停 | 每次硬切都有因果，空间不断裂 |
| 双人同框 | 第 2、5 镜显式 `keeping both in frame` | 保住双角色关系，防单人漂成独角戏 |
| 单主运镜 | 每镜一个运动类型 + 幅度 + 速度，且多与上一镜方向同步 | 避开运镜冲突导致的画面随机 |
| 地标锚点链 | 北门前广场 → 第一 / 第二 / 第三面断墙 | 观众始终知道两人在同一块场地 |
| 招式轮替 | 爪击 → 角冲 → 闪电柱 → 双爪连击 → 交叉对冲 → 投技 → 尾部抽击 → 贯穿 | 相邻镜不重复，强度递进 |
| 弱势方有还手 | 牛在第 2、5 镜反制得手 | 节奏不塌成单方面挨打 |
| 代价可视化 | 火花、两道沟、环状开裂、撞穿三面墙、单膝/双膝跪地 | 每一击都能被看见 |
| 声音分层 | `overall_soundscape` 只写地面 + 龙的电鸣 + 牛的蹄声；配乐单列 | 画内/画外不混，避免模型把配乐塞进画面声 |
| 收尾呼应 | `summary` 的"符文明亮 + 巨影苏醒"在末镜闭合，配乐 `sudden cutoff` | 钩子有始有终，适合做续集或系列 |

## 4. 换题材改写指引

保留骨架，只换这些层：

| 层 | 换法 |
| --- | --- |
| 风格句 | `fast-paced 3D CG fantasy combat style` → 水墨 / 2D 手绘 / 赛博霓虹 / 定格动画等 |
| 身份锁 | 每方 5–7 条可见特征 + 标志性动态；保持"脸干净无伤"与"无多余装饰"两句 |
| 招式体系 | 换成该题材的标志动作（剑技 / 法术 / 机甲 / 拳脚），仍按近战-远程-投技-位移岔开 |
| 场景锚点 | 换成可数的地标（三节车厢、三层平台、三根石柱），仍然只在 1 个场景内 |
| 声音 | 换成双方的标志音（引擎、风铃、电流、骨骼摩擦） |
| 钩子 | 换成该题材的悬念（远方号角、巨大轮廓、第三道身影） |

时长不同时按 §9 的预算表缩放：10 秒用 6–7 镜，5 秒只留 3 镜（建立 / 对冲 / 终结），不要硬塞 9 镜。
